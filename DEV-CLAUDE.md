# FileBrowser (dired) for Sublime Text — Claude notes

## Current work

Branch `attrs-color`: highlighting items by filesystem attributes and other
flags. The design is in **`PLAN-Invisible-Flags.md`**: zero-width Unicode
characters encode a flags field and column/segment separators in each item
line, so the syntax (not regions) does the highlighting. Follow the plan's
phases; Phase 1 is a prototype/verification step before touching the plugin.

`MODEL.md` describes the view model (`dired_index`, expanded paths), which
this plan deliberately does not change.

## Manual test folder

`C:\Users\steve\dired-test-tree` holds items for each flag and link case.
It is generated by `etc/init-dired-test-tree.ps1` (its `README.txt` lists
every link and its target).

- Numbering: a folder and a file with the same number are counterparts (the
  file has an extension). `0x` / `.0` plain folders and files, `2x` junctions
  and hard links, `3x` symlinks, `4x` executables, `90 Targets` holds what the
  links point to.
- Names spell out what the item is (`04 Hidden + System (SuperHidden)`,
  `31 Symlink Relative`, `20 Hardlink.txt`). `Invalid (...)` marks links
  expected to fail: broken targets, a file symlink pointing at a folder.
  `Loop (Self)` links point at themselves and never resolve (WinError 1921);
  `Loop (Root)` links point at the tree root, resolve fine and nest forever.
  "Excluded" items are meant to match `dired_hidden_files_patterns`.
- Every file's content names its own location, so opening an item through a
  link shows where it really lives. A hard link shares its target's
  attributes (they belong to the file, not the name).
- To add specimens, extend the script's `$Spec` table instead of creating
  items by hand: re-running with `-Force` wipes the folder (links are removed
  as links, targets are not touched).
- The full build needs admin rights or Developer Mode (symlinks); ask the
  user to run it. `-Preview` builds the same names as plain items without
  attributes or links and needs no elevation, e.g. into
  `C:\Users\steve\dired-test-tree-preview`.

## Gotchas

- **Never write literal zero-width/format characters into files** (docs or
  code). Write them as `\u200b`-style escapes in Python source and
  `\x{200B}` in syntax regexes. Tools may turn typed escapes into the real
  characters; check with
  `python -X utf8 -c "import unicodedata,sys; print(sum(unicodedata.category(c)=='Cf' for c in open(sys.argv[1],encoding='utf-8').read()))" FILE`.
- `_do_scandir` is wrapped in `lru_cache`: after changing scanning code,
  restart Sublime or reload the plugin before judging results.
- `dired.hidden-color-scheme` / `dired.hidden-tmTheme` are the shipped
  schemes; scope changes need README updates too.
- Sublime's plugin host may run an older Python than the system one; verify
  APIs like `st_reparse_tag` in Sublime's console, not only with system
  Python.
